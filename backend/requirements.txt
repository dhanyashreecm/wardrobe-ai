# wardrobe-ai backend dependencies.
# Install into your own virtual environment:
#   python3 -m venv ai_env
#   source ai_env/bin/activate   (Windows: ai_env\Scripts\activate)
#   pip install -r backend/requirements.txt
#
# Exact versions weren't pinned here (couldn't run `pip freeze` against
# the real macOS venv remotely) - if you hit a version-specific issue,
# run `pip freeze > backend/requirements.txt` from the working ai_env
# on the original machine and commit that instead.

# Added with the shared-database/shared-images change:
#   dnspython  - pymongo needs it to resolve a "mongodb+srv://" Atlas
#                connection string; without it, connecting to Atlas
#                fails with a DNS/SRV error even though the URI is
#                correct.
#   cloudinary - uploads wardrobe photos to shared cloud storage so
#                they load on every computer (see backend/storage.py).
#                Without it the app still runs, saving images to this
#                machine's disk only, and says so at startup.
dnspython
cloudinary
#   certifi    - CA bundle so macOS Python can open TLS to Atlas (db.py).
certifi
